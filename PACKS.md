14 февраля использует любовные наборы. Для «Дня рождения» с отношением «Дружба» автоматически доступны наборы друга.

Набор 1: световые нити → сборка из частиц → раскрытие пространства.
Набор 2: движущийся узор → общая орбита → проявление по плиткам.
Набор 3: открывающаяся страница → коллаж мгновений → световой путь.

Тематические мотивы служат основой для новой постановки. Можно вернуться к прежним рисункам через пункт «Прежние сцены темы».
