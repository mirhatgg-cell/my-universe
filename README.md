# Твоя маленькая Вселенная — v13

Загрузи все файлы из архива в корень существующего репозитория с заменой. Новые обязательные файлы: **scene-experience.js** и **experience.css**. Сохрани scene-setting.js и остальные файлы.

После публикации: https://mirhatgg-cell.github.io/my-universe/create.html?v=13 . Вверху — «Мастерская v13».

## Новые возможности

- **Кинозал** в каждой анимации: крупная сцена поверх страницы. Остальные сцены останавливаются. Выход кнопкой или Escape; фокус клавиатуры остаётся внутри кинозала и возвращается на кнопку после закрытия.
- **Темп**: 0,75× / 1× / 1,5× / 2× отдельно для каждой сцены, без сброса текущего момента. Ускорение v12 сохранено: обычные сцены 10–13 секунд, снеговик 30.
- **Кадр на память**: PNG-открытка 1600×1200 с текущей сценой, именем получателя и подписью отправителя. Сцена отдельно рисуется в 1500×900, независимо от размера экрана. Экспорт локальный; личные данные никуда не отправляются. Это неподвижная открытка, не экспорт видео.
- **Окружение по действию**: отдельная таблица мест для 63 объёмных и 63 бумажных сцен. Обсерватория, театр с кулисами, рабочая мастерская, библиотека, оранжерея и павильон дополняют прежние окружения. В снеговике остаётся его собственный зимний мир. Рисованные сцены сохраняют свою постановку и тематические дальние планы.
- **Разные материалы интерфейса**: объёмные сцены в тёмной рамке, рисунки с паспарту, бумажные миниатюры с бумажной кромкой. Новые заголовки, мягкое раскрытие текста, подписи длительности и навигация с названиями сцен.
- **Личные подписи**: 63 короткие фразы для 21 темы и трёх стилей вместо общей служебной фразы. Три набора одной темы используют эти тематические подписи повторно.

Новые эффекты подчиняются общей паузе и reduced motion. Нет звука с автозапуском, внешних CDN и новых зависимостей.

## Проверка

Canvas: 189 сцен, восемь моментов каждой — 1512 кадров. Просмотрены контактный лист всех бумажных сцен и экспорт открытки. Исправлены повторные солнца в пяти бумажных сценах. DOM-эмуляция: выбор 63 наборов, три стиля, паузы, перемотка, повтор, reduced motion, новые скорости, изоляция кинозала, Escape, возврат фокуса и отрисовка открытки. Проверены синтаксис JS и ссылки на локальные ресурсы.

Полная проверка CSS в браузере, системного скачивания на телефоне и быстродействия на реальном устройстве не выполнена. Тесты не гарантируют отсутствие всех ошибок.

PREVIEW.gif — обзор девяти сцен. Он синхронизирует сцены по доле длительности, а не показывает их фактическую скорость.
