# Твоя маленькая Вселенная — версия 4

## Обновление GitHub Pages

1. Распакуй ZIP.
2. В существующем репозитории загрузи **все файлы из архива в корень**, с заменой старых. Не загружай сам ZIP и не создавай вложенную папку.
3. Нажми Commit changes и дождись успешной публикации Pages.
4. Открой https://mirhatgg-cell.github.io/my-universe/create.html и обнови страницу через Ctrl+F5.

В этой версии есть новые runtime.js, messages.js и supernova.js. Их тоже необходимо загрузить. Все ссылки на ресурсы относительные: сайт работает в подпапке репозитория, без сервера приложения и сборки. CSS и JS имеют параметр ?v=4 для обновления кэша.

## Создание личного поздравления

В мастерской укажи имена, повод, отношение и личные слова. Выбери набор сцен и смысл анимации личного текста. «Посмотреть» покажет письмо ниже. «Скопировать» создаст полную персональную ссылку на index.html#letter=… . Именно её отправляй получателю.

Изменение формы сбрасывает готовую ссылку: после редактирования создай её повторно. Если копирование запрещено браузером, полную ссылку можно выделить и скопировать вручную. Можно открыть готовое письмо в отдельной вкладке.

Получатель видит только своё поздравление. Конверта, редактора, выбора адресата и списка чужих поздравлений на его странице нет. Переход к истории не меняет персональную ссылку. Старые полные ссылки сохраняют совместимость.

## Сцены

Орбиты, процедурное дерево, сердце из частиц, раскрывающийся цветок, подарок и имя из звёзд. Для личного текста доступны отдельные сюжеты: тепло доходит до другой звезды; опора подхватывает и поднимает звезду; шаги прокладывают путь; встреча соединяет орбиты; любовь собирает сердце; уважение сохраняет отдельные пространства.

Есть повтор сцен, реакция на касание, общий режим паузы, уменьшенное движение и одна сверхновая вместо нескольких наложенных эффектов. За пределами экрана сцены не рисуются при наличии IntersectionObserver. При скрытии вкладки общий цикл останавливается. Плотность Canvas и число частиц ограничены. Если WebGL недоступен, остаётся CSS-планета. При недоступном Canvas текст всё равно читается, пустые интерактивные площадки скрываются.

## Файлы

- index.html — поздравление получателя.
- create.html — мастерская с обычной формой.
- style.css — единое оформление без старых конвертов и модальных слоёв.
- runtime.js — единый кадровый цикл и пауза.
- messages.js — тексты и поводы.
- app.js — форма, валидация и персональные ссылки.
- feelings.js — выделение смысловых слов и полный экран.
- journey.js — визуальные сцены и их жизненный цикл.
- cosmos.js — фон и WebGL-планета с запасным вариантом.
- supernova.js — один ограниченный по времени финальный эффект.
- favicon.svg, favicon.ico — иконки вкладки.
- AUDIT.md — найденные проблемы, исправления и границы проверки.

Данные хранятся в самой ссылке. Это персонализация, а не проверка личности: прочитать письмо сможет любой, кому передадут полную ссылку. Мастерская не хранит другие письма. Фото, музыка и база адресатов в эту версию не входят.
