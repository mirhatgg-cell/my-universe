# Твоя маленькая Вселенная

## Обновить сайт
Распакуй архив и загрузи его содержимое в корень существующего репозитория GitHub с заменой файлов. index.html должен лежать в корне, а не во вложенной папке. Нажми Commit changes. В настройках Pages оставь прежнюю ветку и папку /(root).

## Создать поздравление
Открой create.html на своём сайте. Введи имена, повод, отношение, личный текст и выбери анимационную историю. Посмотри письмо, затем скопируй ссылку для отправки. Получателю отправляй именно полную сгенерированную ссылку, а не create.html.

## Новые сцены
journey.js рисует живые сцены на Canvas без внешних библиотек и видео:
- Две самостоятельные орбиты сходятся в общую систему.
- Процедурное дерево растёт от ствола до ветвей; касание зажигает цветы.
- Тысяча частиц собирается в вращающееся сердце; касание рассеивает их.
- Цветок раскрывает двенадцать лепестков; касание повторяет раскрытие.
- Звёзды собираются в имя получателя и реагируют на движение пальца.
- Подарок открывается по нажатию, выпуская светящиеся частицы.

Наборы: для любимой, сюрприз к празднику, тёплая история или автоматический выбор. Каждая сцена сопровождается своим смысловым текстом. Старые абзацы с маленькими смысловыми анимациями тоже сохранены. Есть повтор каждой сцены, пауза движения и поддержка prefers-reduced-motion. Сцены вне экрана не анимируются. Плотность Canvas ограничена для мобильных устройств.

Старые персональные ссылки поддерживаются. Новые настройки хранятся в той же ссылке. Это персонализация, а не защита паролем: письмо доступно любому, кому передадут полную ссылку. Мастерская не показывает ранее созданные письма. Фото и музыка в эту версию не добавлены.

## Состав
index.html — страница получателя; create.html — мастерская; app.js — тексты и ссылки; cosmos.js — космический фон; feelings.js — анимации абзацев; journey.js — большие интерактивные сцены; style.css — оформление; .nojekyll — статическая публикация.

Проверены синтаксис всех JS-файлов, наличие локальных ресурсов и упаковка ZIP. Проверка в браузере в среде разработки недоступна: Chromium не установлен.
